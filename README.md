# Safety Engine — static demo

A static build of the Safety Engine console. It runs entirely in the browser: the fleet, events and live feed are simulated client side, and nothing is saved (a reload starts a fresh demo).

Built from `Arivazhaganr/safety_engine` with `npm run build:static -- swirexdemo`, so it expects to be served from `/swirexdemo/` (GitHub Pages for this repo).
